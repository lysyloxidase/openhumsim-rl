# OpenHumSim-RL v0.22.0

> Research software only. OpenHumSim-RL is not a clinically validated digital
> twin and must not be used for diagnosis, treatment selection, dosing or
> patient-specific prediction.

## Highlights

- Explicit amount and flux ledgers connect achieved oxygen consumption,
  oxidative carbon-dioxide production, oxygen deficit and lactate.
- Pulmonary oxygenation, whole-blood carbon chemistry and Haldane coupling are
  reconciled against the final oxygenation state.
- Respiratory and cardiovascular cycle diagnostics use completed cycles rather
  than partial integration windows.
- Benchmark telemetry is allowlisted to prevent hidden-state and reward-term
  leakage.
- The research dashboard records complete run provenance and distinguishes
  measured observations from latent model truth.

## Compatibility

The state schema is `0.22`, the reward profile remains `homeostasis_v0.21`, and
the clinical/full observation vectors contain 54/138 values. Historical RL
checkpoints are not compatible with this release.

## Verification

The supported-interpreter CI runs the full test suite on Python 3.10, 3.12 and
3.14, executes the v0.22 mechanistic integrity gate, and installs the wheel in
an isolated environment. These are internal invariants and numerical
regressions, not independent external clinical validation.

See [VALIDATION_AUDIT_v0.22.md](https://github.com/lysyloxidase/openhumsim-rl/blob/v0.22.0/VALIDATION_AUDIT_v0.22.md)
for biological, physical, medical and algorithmic limitations.

## Artifacts

The release contains a source distribution, a pure-Python wheel and
`SHA256SUMS`. GitHub build provenance is generated by the release workflow.
